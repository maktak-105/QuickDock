# QuickDock 仕様書

## 1. アプリ概要

- **名称**: QuickDock（クイックドック）
- **目的**: 普段はアイコン1個のコンテナ。ドロップでショートカットを格納し、カーソルを合わせると左にアイコンが並び、クリックで起動する。
- **対象OS**: Windows 10 / 11 (64-bit)
- **実装**: C# / WinForms / .NET 10（`dotnet publish`、win-x64 単体）
- **配布形態**: `dist\QuickDock.exe`（単体）。GitHub Releases の ZIP は未公開。
- **バージョン**: 1.0.0
- **アイコン**: `assets/QuickDock-icon.png`（ガラス棚のドック）。EXE は `src/app/QuickDock.ico`

## 2. 画面

枠なしフローティング。収納時は約 64×64 のドックアイコン。展開時はアイコンが左へ最大横 6 個、それ以上は下の段。常駐ドックのため WebView2 は使わない。

バージョン情報の共通ダイアログは未実装。設定はコンテナ右クリックとトレイアイコン。

## 3. 機能

| 操作 | 動作 |
|------|------|
| 円／展開面に `.lnk` / `.exe` などをドロップ | `%APPDATA%\QuickDock\pins` へコピーして格納 |
| カーソルを乗せる | アイコンを展開（横 6 個まで、以降は下へ） |
| 格納アイコンにカーソル | 名前をポップアップ |
| 格納アイコンを左クリック | 起動 |
| 格納アイコン同士をドラッグ | 並べ替え（`order.txt`） |
| 格納アイコンを右クリック | **管理者として実行**、**削除**（削除は確認あり） |
| ドック本体を左ドラッグ | 画面上を移動。位置を保存 |
| 本体を右クリック／トレイ | **Windows起動時に実行**、**常に前面**、終了 |

Windows起動時の実行設定はユーザー単位でレジストリ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に保存し、現在の実行ファイルを起動する。

## 4. データ

`%APPDATA%\QuickDock\`

| ファイル | 内容 |
|----------|------|
| `pins\` | 格納したショートカット / exe（1ファイル1件） |
| `order.txt` | ドック内の並び（ファイル名） |
| `items.txt` | 旧形式。起動時に `pins\` へ移行 |
| `settings.txt` | `x=` `y=` `w=` `h=`（窓位置）`topmost=`（0/1） |
| `drop.log` | ドロップ診断用 |

## 5. ビルドとテスト

```powershell
scripts\build.bat
powershell -NoProfile -ExecutionPolicy Bypass -File tests\selftest.ps1
```

`tests\selftest.ps1` は窓サイズ、ヒットテスト、D&D 登録、クリック起動を確認する。

## 7. ドロップと管理者権限

エクスプローラーから窓へドロップできない（進入禁止のまま）ときは、**QuickDock が管理者として動いている**ことが多い。

Windows は、権限の低いプロセス（通常のエクスプローラー）から権限の高いプロセス（管理者の QuickDock）へドロップできない。これは WPF / WinForms の違いではない。

- **正しい起動**: `dist\QuickDock.exe` をエクスプローラーからダブルクリック（通常権限）
- **失敗する起動**: 管理者のターミナル / 管理者の AI セッションから起動したままドロップする

管理者でビルドしたあとは、いったん QuickDock を終了し、exe をダブルクリックし直す。

トレイの「常に前面」は任意。ドロップそのものには不要。

## 6. v1 の対象外

- プラグイン、天気、CPU メーター
- 複数コンテナ
- macOS 風の拡大アニメ
- LZH などアーカイブ展開
- GitHub Releases 公開
