QuickDock 3.2.2

Borderless floating dock. Drop shortcuts, hover to expand, click to launch.

Double-click QuickDock.exe in Explorer (not from an elevated terminal).
Explorer cannot drop onto an elevated instance.

Exit from the tray or the dock context menu.
