# 2026-09-20 公開ドック調査 v1.0

Explorer からドロップしてピンする公開アプリを調べた。QuickDock の参考用。

| 名前 | URL | 実装 | ドロップ |
|------|-----|------|----------|
| WindowsDock | https://github.com/maraf/WindowsDock | WPF | ファイルをドックに落とすとショートカット |
| OpenFences | https://github.com/chrisdfennell/OpenFences | WPF | フェンスへ D&D で .lnk 作成 |
| Cedro Modern Dock | https://github.com/Cedro-Software/cedro-modern-dock | C# / JavaFX | Explorer からピン、並び替え |
| Aero Dock | https://github.com/TheAgencyMGE/aero-dock | Rust + WebView2 | Explorer からピン。ドラッグ中はドックを動かさない |
| Hoverdock | https://github.com/thomasboyle/hoverdock | 独自描画 | ファイルドラッグ中は収納しない |
| Seelen-UI | https://github.com/eythaann/Seelen-UI |  | ドックへ .lnk を D&D でピン |
| CleverDock | https://github.com/dlacaille/clever-dock | WPF | テーマ付きドック（保守停止） |
| QuickLaunch | https://github.com/chrizonix/QuickLaunch | C# | フォルダ内ショートカットをツールバー化。ライブドロップではない |
