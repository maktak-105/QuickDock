# QuickDock タスクバー非表示とシステムトレイ常駐強化

## ユーザー指示（原文・2026-09-22）
- 「QuickDockをここに常駐させてタスクバーには表示されないようにしたい、考えて」
- 「修正＆ビルド、V1.1.0でリリース」

## 目的・内容
1. `MainForm.cs` にて `ShowInTaskbar = false` を設定し、タスクバーのタスクリストからドックを除外。
2. `CreateParams` に `WS_EX_TOOLWINDOW`（0x80）を付与し、Alt+Tab タスク切り替え画面からも除外。
3. システムトレイの `NotifyIcon` の左クリックイベントを実装し、トレイアイコンクリックでドックを最前面化・アクティブ化。
4. バージョンを 1.1.0 に更新（csproj, MainForm, docs）。
5. ビルドを行い、v1.1.0 タグを作成して GitHub Release を公開。

## 結果
- `src/app/MainForm.cs`: `ShowInTaskbar = false`、`CreateParams`、`_tray.MouseClick`（左クリック前面化）を実装。
- `src/app/QuickDock.csproj`: 1.1.0 に更新。
- `dist/QuickDock.exe` のビルド成功。
