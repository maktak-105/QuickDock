# 2026-09-20 QuickDock ドロップ登録修正 計画 v1.0

## 目的

コンテナへ `.lnk` / `.exe` をドロップして格納できるようにする。仕様 `docs/spec_jp.md` どおり。

## 原因

ドロップ中にホバー展開で `SetWindowPos` しており、Explorer の OLE ドロップが切れる。

## 今回

1. OLE ドラッグ中・マウスドラッグ中はサイズ変更しない
2. `pdwEffect` は COPY のみ
3. `DragAcceptFiles` を外し `RegisterDragDrop` のみ
4. `OleInitialize` を明示
5. パス取得は WinForms `DataObject` を優先

## 確認

`scripts\build.bat` と `proto\selftest.ps1`
