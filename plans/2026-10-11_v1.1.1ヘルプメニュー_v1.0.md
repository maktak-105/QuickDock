# v1.1.1 ヘルプメニューとバージョン情報 v1.0 (2026-10-11)

## 目的
- 右クリックメニューに「ヘルプ」を追加し、「使い方」「バージョン情報」を開けるようにする。
- Quickシリーズの共通仕様（`11_アプリ仕様.md` 8〜9章）に沿った暗色のバージョン情報画面を作る。
- 関連ドキュメントの版数と説明を 1.1.1 に揃える。

## 完了条件
- 右クリック > ヘルプ > 使い方 / バージョン情報 で、それぞれの画面が開く。
- バージョン情報は、中央のモーダルカード・背景の暗転・版数・開発環境・制作者・制作者ワッペン（幅160px）・OKを表示する。
- 日本語 / English を切り替えても崩れない。
- 版数は csproj の `<Version>` が元データになり、画面にも `Ver. 1.1.1` と出る。
- README / 配布 readme / 変更履歴 / about / spec を 1.1.1 に更新する。

## 実装
- `src/app/HelpForms.cs`（新規）
  - `HelpUi`: 色、版数（`ProductVersion` の `+` より後ろは除く）、言語（OS の表示言語が日本語なら日本語）、ワッペン読み込み。
  - `DarkCard`: 枠なし・角丸・シアンの細い枠の共通カード。言語切替ボタン（地球アイコン付きピル型）と Esc で閉じる。
  - `HelpCard`（使い方）、`AboutCard`（バージョン情報）。
  - `HelpDialogs`: バージョン情報は、全画面の暗いオーバーレイの上にモーダルで表示する。
- `src/app/MainForm.cs`
  - `BuildMenu()`: 「ヘルプ」サブメニュー（使い方 / バージョン情報）を「終了」の上に追加。
  - `ShowHelpDialog()`: 表示中は `_menuOpen` を立て、ドックが閉じないようにする。
  - タイトルのバージョン直書き（`QuickDock 1.1.0`）を `HelpUi.Version` に変更。
- `src/app/QuickDock.csproj`: `Version` 1.1.1 / `FileVersion` 1.1.1.0 / `InformationalVersion` 1.1.1。ワッペン `assets/maktak105-V04-01.jpg` を `QuickDock.badge.jpg` として埋め込み。
